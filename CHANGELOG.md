## [1.0.0] — not yet released

First release. Details in [the release notes](Documentation/RELEASE_NOTES.md) and
[known limitations](Documentation/KNOWN_LIMITATIONS.md).

### Added
- Overview of charge, health, free space, the most active apps, the last scan and the
  last cleanup.
- Battery monitor: charge, health, cycle count, temperature, power draw, time remaining
  and charge history, each value labelled measured, estimated or unavailable.
- Energy: per-app CPU, memory and wake-ups, an energy-impact estimate, trends and
  optional alerts.
- Space Analyzer: safe disk and folder scans with the largest items, categories,
  exclusions and history.
- Duplicate Finder: content-verified groups; hard links counted once; iCloud-only files
  skipped.
- Cleaner: caches, logs, old downloads, empty folders, large files and marked duplicates;
  confirmed moves to the Trash only, re-checked per item, with Put Back.
- Menu bar companion, Settings, open at login (off by default).
- English, and a draft Arabic translation laid out right to left.
- Released under GPL-3.0-or-later, with a contributor licence agreement, contribution
  guide, Code of Conduct, and issue and pull request templates.
